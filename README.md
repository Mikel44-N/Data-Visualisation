# Data-Visualisation
# A Collection of Data Visualisation Projects
This repository contains a collection of Excel-based data visualization projects, ranging from foundational charts to advanced, formula-driven dashboards.
Each project demonstrates practical data storytelling, dashboard design, and Excel’s visualization capabilities — including workarounds for features not natively supported in Excel.
The focus is on clarity, insight, and usability, not just chart creation.

Project Categories
1. Foundational Charts
These projects focus on selecting appropriate chart types and presenting data clearly.
•	Bar & Column Charts
•	Line Charts & Trendlines
•	Area Charts
•	Pie & Donut Charts
•	Scatter & Bubble Charts
•	Box & Whisker Charts
•	Radar Charts
•	Stock Charts
•	Sparklines
Skills demonstrated:
Excel Charts, chart formatting, storytelling with data

2. Comparative & Distribution Visuals
Projects designed to analyze spread, frequency, and comparisons.
•	Histograms & Pareto Charts
•	Heat Maps
•	Surface & Contour Charts
Skills demonstrated:
Conditional formatting, color scales, distribution analysis

3. Hierarchical & Flow Visualizations
Visualizations for structure, composition, and progression.
•	Treemaps & Sunburst Charts
•	Waterfall Charts
•	Funnel Charts
Skills demonstrated:
Hierarchy analysis, contribution tracking, flow visualization

4. Dynamic & Interactive Dashboards
Projects that respond to user input and update automatically.
•	Dynamic Dashboards (INDEX/MATCH, SUMIFS, IFERROR)
•	Combo Charts with dynamic series selection
•	Dynamic series highlighting
•	User-driven metric selection
•	Automated charts using OFFSET, COUNTA, and Named Ranges
Skills demonstrated:
Formulas, data validation, automation, dashboard design

5. Advanced Visualization Techniques
Projects that go beyond native Excel functionality.
•	Custom Gauge Charts (Scatter + Donut + Trigonometry)
•	Image Overlay Charts (goal tracking visuals)
•	Value-based dynamic formatting using PERCENTRANK
•	Custom pacing charts (under/over target visualization)
•	Animated charts showing change over time
•	Binary-value highlighting for date ranges
Skills demonstrated:
Advanced formulas, creative problem-solving, KPI visualization

6. Geospatial & Time-Based Visuals
Location- and time-aware visualizations.
•	Excel 3D Maps (Power Map)
•	Heat maps based on latitude/longitude
•	Time-series animations
Note: Power Maps open in a dedicated Excel window by design. Key views are captured and embedded in dashboards for presentation, while full interactivity remains available within the workbook.

Data Sources
•	Course-generated datasets
•	Public or publicly inspired datasets (e.g., demographic, financial, environmental data)
All datasets are used strictly for learning, demonstration, and portfolio purposes.

Tools & Techniques Used
•	Excel Charts & Dashboards
•	Advanced Formulas (IF, INDEX/MATCH, SUMIFS, OFFSET, COUNTA)
•	Trigonometry (SIN, COS, RADIANS) for visual positioning
•	Conditional Formatting
•	Data Validation
•	Named Ranges
•	Form Controls
•	Storytelling with Data

Purpose of This Repository
This portfolio demonstrates the ability to:
•	Translate raw data into clear visual insight
•	Build dynamic, user-friendly dashboards
•	Solve visualization problems creatively within Excel
•	Communicate results effectively to non-technical stakeholders

How to Use
•	Browse individual folders for specific visualization types
•	Open Excel files to interact with dashboards and visuals
•	Review formulas and chart structures to understand implementation
